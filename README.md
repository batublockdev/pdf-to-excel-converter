# PDF to Excel Converter 🚀

Convierte estados de cuenta PDF a Excel limpio automáticamente.

## 🌐 Links

- **Frontend:** https://pdf-to-excel-converter.vercel.app
- **Backend API:** https://pdf-to-excel-backend-production.up.railway.app
- **GitHub:** https://github.com/batublockdev/pdf-to-excel-converter

## 📦 Productos

1. **Bank Statement Converter** - Estados de cuenta PDF → Excel
2. **PDF to Excel Converter** - Cualquier PDF tabular → Excel

## 🛠️ Stack

- **Backend:** Python + FastAPI + pdfplumber + Gemini AI
- **Frontend:** Next.js + React + TypeScript + Tailwind CSS
- **Deploy:** Railway (backend) + Vercel (frontend)
- **Costo:** $12 total (dominio)

## 🚀 Deploy

### Backend en Railway

```bash
railway init
railway up
railway domain
```

Variables de entorno:
```
GEMINI_API_KEY=tu_key_opcional
```

### Frontend en Vercel

```bash
vercel
```

Variables de entorno:
```
NEXT_PUBLIC_API_URL=https://tu-backend.railway.app
```
